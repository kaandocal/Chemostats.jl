Cells

Cells in Chemostats.jl can be of any user-defined type that implements the cell interface. For models defined using DifferentialEquations.jl, the DECell class provides a direct wrapper.

DifferentialEquations.jl models

DECell also supports models defined using the wider SciML ecosystem, e.g. using ModelingToolkit.jl and Catalyst.jl.

To use this functionality we require:

  • An AbstractDEProblem describing how the cells behave
  • A DivideCallback provided to the AbstractDEProblem
  • A divide function

Chemostats.jl supports AbstractDEProblems with arbitrary parameters p and state vectors u. This problem should include a DivideCallback to determine when a cell has reached the end of its life, either due to division or death. When a cell reaches the end of its life, the divide function is called to determine the daughter cells.

The divide argument should be a function of the form int -> offspring that takes a single argument int, the integrator of the cell, and returns an Offspring object describing the daughter cells. This function can return nothing if there are no offspring. Alternatively, a fixed Offspring object can be passed directly.

# When the cell divides, the volume is halved, ribosomes are partitioned binomially,
# and each daughter draws a new cell cycle duration
Offspring(2, :V => ExactPartition(), :R => BinomialPartition(), :τ => Gamma(5, 1))

# Alternative: die with probability 1/10, otherwise divide asymmetrically
function divide(int)
    rand() < 0.1 && return nothing

    f = rand(Beta(20, 20))
    Offspring(:V => ExactPartition([f, 1 - f]), :R => BinomialPartition([f, 1 - f]))
end

Deprecated: divide can return a vector of NamedTuples with fields u0 and p, the initial state and parameters of each daughter cell. This is needed to change parameters without symbolic names, e.g. a NamedTuple of parameters.

Chemostats.DECell — Type
DECell(prob, alg, divide; t0 = 0., reset_t=false, remake::Bool=false, rng=Xoshiro(rand(UInt64)))

Creates a new cell around a SciMLBase.DEProblem, simulated with algorithm alg starting at time t0. The function divide takes a single integrator argument int and returns a list of offspring as a vector of NamedTuples with fields u0 and p.

reset_t determines whether the integration time is started from 0 for every cell, which can avoid floating-point errors for long simulations (many generations). If reset_t is set to true, each cell should keep track of its starting time, e.g. via a parameter t0 in p.

If remake is true, descendants will be created using SciMLBase.remake, which creates a copy of the underlying AbstractProblem (safest). Otherwise, descendants will be created using SciMLBase.reinit, which should be faster for ODEProblem and SDEProblem types.

If a population tree is recorded, the solution int.sol of each cell is saved for each cell. This can be changed by overriding Chemostats.get_data.

Note: The problem should include a callback that calls terminate! when a cell reaches the end of its life.

Chemostats.DivideCallback — Function
DivideCallback(condition; discrete=false, kwargs...)

Implements a differential equation callback to check whether a cell has reached the end of its lifetime. If discrete=false (default), returns a ContinuousCallback that calls terminate! once condition equals zero. If discrete=true, returns a DiscreteCallback.

source
Chemostats.Offspring — Type
Offspring([n,] rules...)

Describes initial conditions and parameters for the n offspring of a dividing cell. Each rule is of the form var => value, where value can be one of the following:

  • ExactPartition(f): var is divided exactly among the offspring
  • BinomialPartition(f): var is partitioned binomially among the offspring
  • AllOrNothingPartition(f): var goes entirely to one offspring
  • [ val1, val2, ..., valn ]: the i-th offspring gets the i-th value
  • val: each offspring gets val,
  • dist::Distribution: each offspring gets an independent random sample from dist

Variables are given as symbols, or a CartesianIndex. All other variables are copied from the parent.

An Offspring can be used as the divide keyword of a DECell. Alternatively, divide can be a function int -> offspring that returns an Offspring object.

source
Chemostats.ExactPartition — Type
ExactPartition(f = nothing)

Divides x among all offspring, such that offspring i receives f[i] * x. The fractions f must be nonnegative and sum to 1. By default, x is divided equally.

source
Chemostats.BinomialPartition — Type
BinomialPartition(f = nothing)

Divides a count x (rounded to an integer) among the offspring of a cell, following a multinomial distribution. Each molecule is independently assigned to offspring i with probability f[i]. The fractions f must be nonnegative and sum to 1. By default, all offspring are equally likely.

source
Chemostats.AllOrNothingPartition — Type
AllOrNothingPartition(f = nothing)

Assigns all of a quantity x to a single offspring, chosen at random with probabilities f. The probabilities f must be nonnegative and sum to 1. By default, all offspring are equally likely.

Custom cells

Cells of a user-defined type must implement the following functions.

Chemostats.get_curr_t — Function
get_curr_t(cell)

Returns the current simulation time t of the cell.

source
Chemostats.get_state — Function
get_state(cell)

Returns the current cell state, see CellState.

source
Chemostats.divide! — Function
divide!(cell)

Called after a cell divides, as determined by Chemostats.get_children. After this call, Chemostats.get_state should return Divided.

source
Chemostats.die! — Function
die!(cell)

Called after a cell dies, as determined by Chemostats.get_children. After this call, Chemostats.get_state should return Dead.

source
Chemostats.kill! — Function
kill!(cell, t)

Called when a cell is killed by the simulation algorithm. The argument t is the time at which a cell is killed. Unless the cell is already dead, Chemostats.get_state should return Killed.

source
Chemostats.get_children — Function
get_children(parent, args...)

Returns an array of cells representing the offspring of the given cell.

source
Chemostats.clone_cell — Function
clone_cell(cell, t)

Creates an independent copy of the cell at time t. Used by Chemostats.Strict to maintain a constant population size.

source
Chemostats.get_cell_rng — Function
get_cell_rng(cell)

Returns the random number generator owned by cell.

source
Chemostats.get_data — Function
get_data(cell)

Returns the data saved for cell in the population tree. Defaults to nothing.
