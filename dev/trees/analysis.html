Lineage analysis

We use a small random tree in which the data of each cell is a random number.

using Chemostats.Trees
using Chemostats.Trees: cell_init!, cell_divide!, cell_die!, cell_update!
using Random
using StatsBase

mutable struct Cell end

Random.seed!(1)
tree = Tree{Cell,Float64}()
cells = [ Cell() for _ in 1:20 ]
cell_init!(tree, cells, 0.)

for t in 0.1:0.1:20
    i = rand(eachindex(cells))
    c = cells[i]
    kids = [ Cell(), Cell() ]
    cell_divide!(tree, c, kids, t, rand())
    cells[i] = kids[1]

    # Keep the population size constant by replacing a random cell
    j = rand(eachindex(cells))
    cell_die!(tree, cells[j], t, rand())
    cells[j] = kids[2]
end

foreach(c -> cell_update!(tree, c, 20., rand()), cells)
sort!(tree)
Tree{Main.Cell}(410 nodes, 20 living)

Selecting cells

Most analysis functions take arbitrary node collections, which can be:

  • a tree, using values(tree)
  • a subtree view(tree, ids)[@ref Base.view(::Tree, ::Any)]
  • cells satisfying certain conditions, using filter(f, nodes)
  • ancestors of a cell using ancestors(tree, id)
  • descendants of a cell using descendants(tree, id)

For these collections, keys returns the cell ids, values the nodes, and pairs returns id => node.

id = first(keys(living(tree)))
lineage = ancestors(tree, id; self=true, tspan=(5., 20.))
late = filter(node -> node.t_birth >= 5, tree)
length(collect(lineage)), length(late)
(18, 293)

Observables and summaries

Trees uses two kinds of user-defined functions:

  • Observables f(node, a) of a cell at age a (time since birth). This could be a cell's position, size, protein content etc.
  • Per-cell summaries f(node) of a Node, e.g. its lifetime, or the time average of an observable using time_average(f, node).
Chemostats.Trees.time_average — Function
time_average(f, node::Node; tspan = (-Inf, Inf), integrate)
time_average(f; tspan = (-Inf, Inf), integrate)

Returns the time average of f(node, age) over the cell's lifetime, truncated to lie within tspan. Returns nothing for nodes without data, or for cells not alive within tspan.

time_average(f; kwargs...) is a convenience wrapper for node -> time_average(f, node; kwargs...).

Time averages are computed by integration, using the callback integrate(f, node, a, b). By default, this uses adaptive Gaussian quadrature (QuadGK.jl).

Population and lineage statistics

mean, var and mean_and_var are defined for trees and lineages. To compute time-averages, use time_weights to weight cells by their lifetime.

age(node, a) = a
avg_age = time_average(age)

mean(avg_age, late),                                    # per cell
mean(avg_age, tree, time_weights),         # time-weighted, over the population
mean(avg_age, lineage, time_weights)    # time-weighted, along a lineage
(0.4792096219931269, 0.948125, 0.5606666666666666)
Chemostats.Trees.time_weights — Function
time_weights(node::Node; tspan = (-Inf, Inf))
time_weights(; tspan = (-Inf, Inf))

Weights cells by their lifetime within tspan (living cells up to their last update). Used to compute time averages in lineages and populations. time_weights(; tspan) returns the function node -> time_weights(node; tspan).

source
Statistics.mean — Method
mean(f, nodes)
mean(f, nodes, w)

Returns the mean of f(node) over all nodes in nodes, optionally weighted by w. The default returns the average over cells; if w = time_weights, returns time averages. Ignores nodes where f returns nothing.

For example:

# Time average of an observable `f(node, age)` over the population within `tspan`
mean(time_average(f; tspan), tree, time_weights(; tspan))

# Mean lifetime of the cells along the backward lineage of node `id`
mean(lifetime, ancestors(tree, id))
source
Statistics.var — Method
var(f, nodes; corrected=true)
var(f, nodes, w; corrected=true)

Returns the variance of f(node) over all nodes in nodes, optionally weighted by w, see mean. If corrected=true, applies Bessel's correction (for probability weights).

Note: This is the variance of per-cell summaries. The variance of per-cell averages is smaller than the variance across the population (law of total variance).

source
StatsBase.mean_and_var — Method
mean_and_var(f, nodes; corrected=true)
mean_and_var(f, nodes, w; corrected=true)

Returns the mean and variance of f(node) over all nodes in nodes in a single pass, optionally weighted by w, see mean and var. If corrected=true, applies Bessel's correction to the variance (for probability weights).

Snapshots

snapshot(f, nodes, t) evaluates an observable over all cells alive at time t. t can be an array, in which case multiple snapshots are pooled.

[ mean(snapshot(age, tree, t)) for t in (10., 15.) ]

 0.9349999999999998
 1.01
