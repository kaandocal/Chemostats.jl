Tree API

Trees and nodes

A Tree stores one Node per cell as a StructVector under tree.nodes. Each node records the parent, generation, birth time and end time of a cell, and a user-defined field data. For living cells, the end time is the time of their last update.

Nodes are internally identified by their id and can be accessed as tree[id]. Since tree.nodes is a StructVector, fields can also be accessed for all cells at once, e.g. tree.nodes.t_birth.

Cells are stored approximately in order, but some operations require the tree to be exactly sorted, achieved using sort!(tree).

Note: The id of a node is not stable and can change when calling sort! or prune!.

Chemostats.Trees.Tree — Type
Tree{C,P=Any}(; min_sweep=1024)

Creates a population tree. Here C is the type of a cell, and P is the type of the data saved for each cell (at division, death or updates), Any if omitted. Each cell is stored in a Node.

min_sweep is a parameter used for pruning (see prune!).

Every node in the tree has a unique ID, and nodes can be accessed as tree[id]. IDs are not stable, and can change when the tree is pruned or sorted.

Cells are implicitly stored as pairs id => node, and these can be extracted using the functions keys, values and pairs.

Update the cell's current time to t; if data is provided, updates the cell's saved data. Should be called for each living cell before doing tree operations (e.g. at the end of a simulation).

Pruning cells

For large trees, prune!(tree) performs garbage collection by removing unused branches: only cells that are currently alive or marked using mark! are retained, together with their ancestors.

Chemostats.Trees.mark! — Function
mark!(tree)
mark!(tree, ids)
mark!(tree, nodes)

Marks the nodes ids (or the node collection nodes) to be kept by pruning, together with their ancestors. mark!(tree) marks the current population, i.e. all living cells.

source
Chemostats.Trees.prune! — Function
prune!(tree::Tree; lazy=false)

Removes all "dead" nodes, i.e. nodes that are not ancestors of living cells or of marked nodes (see mark!). If lazy=true, only prunes if the tree has doubled in size since the last pruning.

Export

Trees can be exported in Newick format, which can be read by many tree-handling packages.

Chemostats.Trees.newick — Function
newick(nodes; label = nothing, annotate = nothing)
newick(io::IO, nodes; label = nothing, annotate = nothing)

Returns the nodes of the node collection nodes in Newick format. Nodes whose parent is not in nodes are treated as roots. Branch lengths are lifetimes. Requires a sorted tree.

Nodes are labelled by their ids, or by label(node) if given. If given, annotate(node) returns a named tuple (or nothing) to be added as an annotation of the form [&key=value,...].
